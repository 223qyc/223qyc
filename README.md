## About Me

- 🎓 Senior undergraduate at **China University of Geosciences (Wuhan)**, majoring in **Computer Science and Technology**
- 🚀 Incoming graduate student at **ShanghaiTech University**
- 🔬 Research interests: **Reinforcement Learning**, **Large Language Models**, **RLHF**, **Tool-Using Agents**, **Reward Design**, **Credit Assignment**
- 🛠️ Prefer building **complete, testable, reproducible pipelines** instead of one-off demos
- 🧠 Especially interested in **LLM + sandbox / code interpreter**, agent tool-use policy, and optimization behavior

- ✍️ I document what I learn through **notes, experiments, and repositories**
